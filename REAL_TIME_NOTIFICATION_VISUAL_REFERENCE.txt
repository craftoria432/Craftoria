BEFORE (One-time load - NO real-time updates):
┌─────────────────────────────────────────────────────────────────────────────┐
│ NotificationViewModel                                                       │
│                                                                             │
│  loadNotifications(userId)                                                 │
│         ↓                                                                   │
│  notificationRepository.getUserNotifications()  ← One-time call            │
│         ↓                                                                   │
│  _notifications.value = fetchedNotifications                              │
│         ↓                                                                   │
│  NotificationsScreen displays notifications                               │
│                                                                             │
│  ❌ Member joins store → member_count NOT updated                         │
│  ❌ Store name changes → store_name NOT updated                           │
│  ❌ User must manually refresh to see changes                             │
└─────────────────────────────────────────────────────────────────────────────┘


AFTER (Real-time listener - AUTOMATIC updates):
┌─────────────────────────────────────────────────────────────────────────────┐
│ NotificationViewModel                                                       │
│                                                                             │
│  loadNotifications(userId)                                                 │
│         ↓                                                                   │
│  db.collection("notifications")                                            │
│    .whereEqualTo("user_id", userId)                                        │
│    .addSnapshotListener { snapshot, error →  ← REAL-TIME LISTENER        │
│         ↓                                                                   │
│  Parse notifications from snapshot                                         │
│         ↓                                                                   │
│  Apply current filter (ALL, ORDERS, MESSAGES, etc.)                       │
│         ↓                                                                   │
│  _notifications.value = filteredNotifications                             │
│         ↓                                                                   │
│  NotificationsScreen recomposes with updated data                         │
│                                                                             │
│  ✅ Member joins store → member_count updates INSTANTLY                   │
│  ✅ Store name changes → store_name updates INSTANTLY                     │
│  ✅ No manual refresh needed                                              │
│  ✅ Filter works with real-time updates                                   │
└─────────────────────────────────────────────────────────────────────────────┘

LISTENER LIFECYCLE:
┌──────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│  NotificationsScreen Opened                                                 │
│         ↓                                                                    │
│  LaunchedEffect(user.id) {                                                  │
│    notificationViewModel.loadNotifications(user.id)  ← Starts listener      │
│    notificationViewModel.startListening(user.id)     ← Badge listener       │
│  }                                                                           │
│         ↓                                                                    │
│  Listener Active                                                             │
│  ┌────────────────────────────────────────────────────────────────────┐    │
│  │ notificationsListener = db.collection("notifications")            │    │
│  │   .whereEqualTo("user_id", userId)                                │    │
│  │   .addSnapshotListener { ... }  ← Listening for changes           │    │
│  │                                                                    │    │
│  │ Updates flow in real-time:                                        │    │
│  │ - Member joins store → member_count updates                       │    │
│  │ - Store name changes → store_name updates                         │    │
│  │ - New notifications → appear instantly                            │    │
│  │ - Notifications deleted → removed instantly                       │    │
│  └────────────────────────────────────────────────────────────────────┘    │
│         ↓                                                                    │
│  NotificationsScreen Closed                                                 │
│         ↓                                                                    │
│  ViewModel.onCleared() {                                                    │
│    stopListening()  ← Removes both listeners                                │
│  }                                                                           │
│         ↓                                                                    │
│  Listener Stopped                                                            │
│  ┌────────────────────────────────────────────────────────────────────┐    │
│  │ badgeListener?.remove()                                            │    │
│  │ notificationsListener?.remove()  ← Cleanup                         │    │
│  │ No memory leaks                                                    │    │
│  └────────────────────────────────────────────────────────────────────┘    │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                        TROUBLESHOOTING                                       │
└─────────────────────────────────────────────────────────────────────────────┘

Issue: Offline banner always shows
  Solution: Check navigator.onLine in console
  console.log(navigator.onLine); // Should be true if online

Issue: Notifications not loading
  Solution: Check browser console for errors
  1. Open DevTools Console
  2. Look for error messages
  3. Check Firestore rules

Issue: Retry not working
  Solution: Verify Firestore rules allow retries
  1. Check rules don't rate-limit
  2. Verify auth token is valid

Issue: Memory leak
  Solution: Ensure cleanup on unmount
  useEffect(() => {
    return () => unsubscribe?.();
  }, []);

================================================================================

User clicks action button
    │
    ├─ Modal opens
    │
    ├─ User adds notes (optional)
    │
    ├─ User clicks Confirm
    │
    ├─ Firestore document updated
    │   ├─ status field changed
    │   ├─ timestamp added
    │   └─ audit_trail entry added
    │
    ├─ Real-time listener fires
    │
    ├─ React state updated
    │
    ├─ UI re-renders
    │
    └─ Toast notification shown


KEYBOARD SHORTCUTS
================================================================================

Tab Navigation:
  - Click "Orders" button → Switch to Orders tab
  - Click "Refunds" button → Switch to Refunds tab

Refund Actions:
  - Click 👁 icon → View details
  - Click ✓ icon → Approve refund
  - Click ✗ icon → Reject refund
  - Click ➤ icon → Process refund

Modal Navigation:
  - Click [Close] or [Cancel] → Close modal
  - Click [Confirm] → Confirm action
  - Escape key → Close modal

TROUBLESHOOTING VISUAL GUIDE
================================================================================

Issue: Refunds not showing
  → Check Firestore rules
  → Verify admin token
  → Check browser console

Issue: Actions not working
  → Check user permissions
  → Verify Firestore rules
  → Check network requests

Issue: Timestamps wrong
  → Check browser timezone
  → Verify Firestore format

Issue: Modal not opening
  → Check component imports
  → Verify state management
  → Check browser console

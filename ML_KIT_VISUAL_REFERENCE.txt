DATA FLOW DIAGRAM
=================

Mobile (Android)
    ↓
User takes selfie
    ↓
ML Kit detects face
    ├─ Validates quality
    ├─ Calculates confidence (0-100%)
    └─ Returns FaceVerificationResult
        ├─ isValid: true/false
        ├─ confidence: 87.5
        ├─ faceCount: 1
        └─ message: "Face verified successfully!"
    ↓
Upload to Cloudinary
    ↓
Save to Firebase (seller_verifications)
    ├─ imageUrl: "https://cloudinary.com/..."
    ├─ mlKitResult: {...}
    ├─ verificationStatus: "pending"
    └─ timestamp
    ↓
Web Dashboard
    ↓
Admin sees quality card
    ├─ Confidence: 87.5% (Green)
    ├─ Quality: Excellent
    ├─ Recommendation: Safe to approve
    └─ Metrics: 1 face, Valid, Pass
    ↓
Admin approves
    ↓
Log to ml_kit_audit_logs
    ├─ decision: "approved"
    ├─ mlKitConfidence: 87.5
    ├─ adminEmail: "admin@example.com"
    └─ timestamp

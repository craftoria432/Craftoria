5. REAL-TIME UPDATE FLOW
================================================================================

SELLER DASHBOARD:
1. Seller viewing dashboard
2. Badge shows "0" (no pending orders)
3. ↓
4. BUYER PLACES ORDER (in real-time)
5. ↓
6. Firestore listener detects new order
7. ↓
8. newOrdersCount updates to "1"
9. ↓
10. Badge appears with count "1"
11. ↓
12. Pulsing animation starts automatically
13. ↓
14. Animation continues until order is viewed
15. ↓
16. Seller clicks Orders → views order
17. ↓
18. Order marked as viewed
19. ↓
20. Badge count decreases
21. ↓
22. When count = 0, badge disappears


6. SCROLL BEHAVIOR DETAILS
================================================================================

AUTOSCROLL CALCULATION:
- Find first incomplete item: order.timeline.indexOfFirst { !it.isCompleted }
- Calculate scroll position: index * 120dp (approximate item height)
- Delay: 300ms (allows dialog to render)
- Animation: animateScrollTo() with default easing

SCROLL DISTANCE EXAMPLE:
- Item 0 (Completed): 0dp
- Item 1 (Pending): 120dp ← AUTOSCROLL TARGETS HERE
- Item 2 (Pending): 240dp
- Item 3 (Pending): 360dp

MANUAL SCROLL:
- Works normally after autoscroll completes
- User can scroll up/down freely
- Smooth scrolling with momentum

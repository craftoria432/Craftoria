💰 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

BEFORE:
  Buyer pays: PKR 1000
  Seller receives: PKR 1000
  Admin receives: PKR 0

AFTER (with 5% commission):
  Buyer pays: PKR 1000
  Commission: PKR 50 (deducted from seller)
  Seller receives: PKR 950
  Admin receives: PKR 50

🚀 QUICK START (3 STEPS)
═══════════════════════════════════════════════════════════════════════════

STEP 1: Deploy Firestore Rules
  1. Open Firebase Console
  2. Go to Firestore → Rules
  3. Copy from COMMISSION_FIRESTORE_RULES.txt
  4. Click Publish

STEP 2: Initialize Settings
  val settings = CommissionSettings(
      commissionRate = 5.0,
      enabled = true
  )
  commissionRepository.updateCommissionSettings(settings)

STEP 3: Test Commission Creation
  1. Create test order
  2. Verify seller payment is less
  3. Check admin_commissions collection
  4. Verify admin_earnings updated


📊 FIRESTORE COLLECTIONS
═══════════════════════════════════════════════════════════════════════════

  └─ Individual commission records
     - One per order/seller
     - Tracks amount, status, dates

admin_earnings
  └─ Aggregated earnings summary
     - Updated automatically
     - Shows total, pending, paid

commission_settings
  └─ Configuration document
     - Commission rate (default 5%)
     - Settlement days (default 7)

═══════════════════════════════════════════════════════════════════════════════
  KEY DIFFERENCES: FIRST-TIME vs UPGRADE
═══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────────┐
│ FIRST-TIME SELLER (This Fix)                                                │
└─────────────────────────────────────────────────────────────────────────────┘

    User has NO account
           │
           ▼
    Selects "Seller" on Role Selection
           │
           ▼
    role = "seller" (IMMEDIATE)
    seller_app = "approved" (AUTO)
    verified = false
           │
           ▼
    Must complete verification
           │
           ▼
    Admin approves → verified = true
           │
           ▼
    Access Seller Dashboard


┌─────────────────────────────────────────────────────────────────────────────┐
│ BUYER UPGRADING TO SELLER (Separate Flow)                                   │
└─────────────────────────────────────────────────────────────────────────────┘

    User has BUYER account
           │
           ▼
    Clicks "Become a Seller" in Profile
           │
           ▼
    role = "buyer" (STAYS BUYER)
    seller_app = "pending" (NEEDS APPROVAL)
           │
           ▼
    Admin reviews application
           │
           ▼
    Admin approves → role = "seller"
           │
           ▼
    Must complete verification
           │
           ▼
    Admin approves → verified = true
           │
           ▼
    Access Seller Dashboard

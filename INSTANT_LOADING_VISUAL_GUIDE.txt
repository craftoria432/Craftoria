═══════════════════════════════════════════════════════════════════════════════

                                              ↑
                                         Delay here!


With Preloading:
═══════════════════════════════════════════════════════════════════════════════

User clicks button → Load data in background → Navigate → Screen opens → Content ready!
                                                                         ↑
                                                                    Instant!

Code Example:
─────────────
Button(onClick = {
    scope.launch {
        // ✅ Preload before navigation
        ScreenTransitionOptimizer.preloadScreen("orders") {
            orderViewModel.loadOrders(userId)
        }
        navController.navigate("orders")
    }
}) {
    Text("View Orders")
}

                              QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

Key Components:
───────────────
1. ScreenLoadingOptimizer<T>  - Handles caching and loading
2. InstantLoadingStateManager  - Manages loading states
3. ScreenTransitionOptimizer   - Preloads before navigation

Key States:
───────────
• isFirstLoad    - true only on first visit (show full loading)
• isRefreshing   - true during background refresh (show subtle indicator)
• data           - The actual data (always available, may be cached)

Integration Steps:
──────────────────
1. Add optimizer to ViewModel
2. Expose state flows (data, isFirstLoad, isRefreshing)
3. Update screen to show cached data instantly
4. Only show full loading when isFirstLoad && data.isEmpty()
5. Show subtle indicator when isRefreshing

Cache Management:
─────────────────
• Auto-expires after 5 minutes (configurable)
• Clear on logout: ScreenLoadingOptimizer.clearAllCaches()
• Force refresh: optimizer.loadData(forceRefresh = true)
• Manual update: optimizer.updateData(newData)

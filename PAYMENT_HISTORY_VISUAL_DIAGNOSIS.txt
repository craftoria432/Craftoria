╚══════════════════════════════════════════════════════════════════════════════╝

┌──────────────────────────────────────────────────────────────────────────────┐
│ STATUS: ❌ BUG (Data Issue)                                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ ROOT CAUSE:                                                                  │
│ ───────────                                                                  │
│ Your Firestore database has payment records with items_count = 0            │
│                                                                              │
│ WHY THIS HAPPENED:                                                           │
│ ──────────────────                                                           │
│ When payments were created, the calculation failed:                         │
│                                                                              │
│   itemsCount = sellerItems.sumOf { it.quantity }                            │
│                ↓                                                             │
│   itemsCount = 0  (because items had quantity = 0 or items array was empty) │
│                                                                              │
│ POSSIBLE CAUSES:                                                             │
│ ────────────────                                                             │
│ 1. Orders were created in legacy format (no items array)                    │
│ 2. Cart items had quantity = 0                                              │
│ 3. Data migration issue from old format                                     │
│                                                                              │
│ HOW TO FIX:                                                                  │
│ ───────────                                                                  │
│ Run this command:                                                            │
│                                                                              │
│   node fix-payment-items-count.mjs                                           │
│                                                                              │
│ This will:                                                                   │
│ 1. Find all payments with items_count = 0                                   │
│ 2. Fetch the corresponding order                                            │
│ 3. Calculate correct item count from order data                             │
│ 4. Update the payment record                                                │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

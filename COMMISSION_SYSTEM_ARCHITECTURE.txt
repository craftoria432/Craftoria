SCENARIO: Order with 2 sellers, 5% commission rate

┌─────────────────────────────────────────────────────────────────────────────┐
│ SELLER A (Original Seller)                                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ Product Price:           PKR 600                                            │
│ Commission Rate:         5%                                                 │
│ Commission Amount:       PKR 30 (600 × 0.05)                               │
│ Seller Payout:           PKR 570 (600 - 30)                                │
│                                                                             │
│ Records Created:                                                            │
│ 1. seller_payments: amount = 570, status = pending                         │
│ 2. admin_commissions: commission_amount = 30, status = pending             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ SELLER B (Original Seller)                                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ Product Price:           PKR 400                                            │
│ Commission Rate:         5%                                                 │
│ Commission Amount:       PKR 20 (400 × 0.05)                               │
│ Seller Payout:           PKR 380 (400 - 20)                                │
│                                                                             │
│ Records Created:                                                            │
│ 1. seller_payments: amount = 380, status = pending                         │
│ 2. admin_commissions: commission_amount = 20, status = pending             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ ADMIN EARNINGS                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ Total Commission:        PKR 50 (30 + 20)                                  │
│ Pending Commission:      PKR 50                                             │
│ Paid Commission:         PKR 0                                              │
│ Total Orders:            1                                                  │
│                                                                             │
│ Record Updated:                                                             │
│ admin_earnings: total_commissions += 50, pending_commissions += 50         │
└─────────────────────────────────────────────────────────────────────────────┘

SUMMARY:
- Buyer paid: PKR 1000 (600 + 400)
- Seller A received: PKR 570
- Seller B received: PKR 380
- Admin received: PKR 50
- Total: PKR 1000 ✓

================================================================================

─────────────────────────────────────────────────────────────────────────

Firestore Timestamp       →  .toDate().time               →  Long (milliseconds)
Number (Int, Double, etc) →  .toLong()                    →  Long
String                    →  .toLongOrNull()              →  Long or null
Map (Firestore format)    →  (seconds * 1000) + nanos     →  Long (milliseconds)
null                      →  Return null                  →  null
Other types               →  Return null                  →  null

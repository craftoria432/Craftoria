║                      KEY CHANGES ON APPROVAL                                   ║
╚════════════════════════════════════════════════════════════════════════════════╝

WHEN SELLER/ADMIN APPROVES REFUND:

1. RefundRequest.status
   BEFORE: REQUESTED
   AFTER:  APPROVED_BY_SELLER (or APPROVED_BY_ADMIN)

2. SellerPayment.status ⭐ CRITICAL
   BEFORE: COMPLETED
   AFTER:  PROCESSING
   WHY:    Signals that payment is no longer in final state, refund is being handled

3. SellerPayment.refundAmount ⭐ CRITICAL
   BEFORE: 0.0
   AFTER:  <refund_amount>
   WHY:    Tracks how much is being refunded

4. SellerPayment.refundReason
   BEFORE: ""
   AFTER:  <reason_from_refund_request>
   WHY:    Audit trail for why refund was issued

5. SellerPayment.refundDate
   BEFORE: null
   AFTER:  null (still null - only set when COMPLETED)
   WHY:    Only set when refund actually completes

╔════════════════════════════════════════════════════════════════════════════════╗
║                      KEY CHANGES ON COMPLETION                                 ║
╚════════════════════════════════════════════════════════════════════════════════╝

WHEN REFUND COMPLETES:

1. RefundRequest.status
   BEFORE: PROCESSING
   AFTER:  COMPLETED

2. SellerPayment.status ⭐ CRITICAL
   BEFORE: PROCESSING
   AFTER:  REFUNDED
   WHY:    Indicates refund has been successfully processed

3. SellerPayment.refundDate ⭐ CRITICAL
   BEFORE: null
   AFTER:  System.currentTimeMillis()
   WHY:    Marks when refund was actually completed

PAYMENT HISTORY SCREEN:
─────────────────────────

if (payment.status == "refunded") {
    showStatus("✅ Refunded")
    showRefundAmount(payment.refundAmount)
} else if (payment.status == "processing" && payment.refundAmount > 0) {
    showStatus("⏳ Refund Processing")
    showRefundAmount(payment.refundAmount)
} else if (payment.status == "completed") {
    showStatus("✅ Completed")
} else {
    showStatus(payment.status.uppercase())
}

MY ORDERS SCREEN:
─────────────────

when (refundState) {
    NONE -> {
        if (daysSinceDelivery <= 30) {
            showButton("Request Refund", orange)
        }
    }
    REQUESTED -> {
        showBadge("Refund Pending", orange)
    }
    APPROVED, PROCESSING -> {
        showBadge("Refund Processing", blue, spinner)
    }
    COMPLETED -> {
        showBadge("Refund Done", green, checkmark)
    }
    REJECTED -> {
        showButton("Resubmit Refund", orange)
    }
    FINAL_DECISION -> {
        showBadge("Refund Denied", gray)
    }
}

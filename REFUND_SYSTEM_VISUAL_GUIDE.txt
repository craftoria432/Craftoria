┌─────────────────────────────────────────────────────────────────────────────┐
│ 3. PAYMENT GATEWAY INTEGRATION                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  RefundProcessor.processApprovedRefund()                                    │
│       │                                                                      │
│       ├─→ processWithPaymentGateway()                                       │
│       │   │                                                                  │
│       │   ├─→ STRIPE                                                        │
│       │   │   ├─ Call Stripe API                                            │
│       │   │   ├─ Create refund                                              │
│       │   │   └─ Get refund ID                                              │
│       │   │                                                                  │
│       │   ├─→ PAYPAL                                                        │
│       │   │   ├─ Call PayPal API                                            │
│       │   │   ├─ Process refund                                             │
│       │   │   └─ Get refund ID                                              │
│       │   │                                                                  │
│       │   └─→ COD (Cash on Delivery)                                        │
│       │       ├─ Manual processing                                          │
│       │       ├─ Log refund                                                 │
│       │       └─ Generate refund ID                                         │
│       │                                                                      │
│       ├─→ If Success                                                        │
│       │   ├─ completeRefund()                                               │
│       │   ├─ updatePaymentRefundInfo()                                      │
│       │   └─ updateOrderStatus()                                            │
│       │                                                                      │
│       └─→ If Failure                                                        │
│           ├─ markRefundFailed()                                             │
│           ├─ Increment retry count                                          │
│           └─ Schedule retry                                                 │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐

│  │                                                                           │
│  ├─→ calculateRefundSplits()                                                │

│  │   ├─ Seller A: ₹3000 × (5000/5000) = ₹3000                              │
│  │   └─ Seller B: ₹2000 × (5000/5000) = ₹2000                              │
│  │                                                                           │
│  └─→ processRefundSplits()                                                  │
│      ├─ Process Seller A refund                                             │
│      └─ Process Seller B refund                                             │
│                                                                              │
│  Partial Refund Example: ₹2500 (50%)                                        │
│  │                                                                           │
│  ├─→ calculateRefundSplits()                                                │
│  │   │                                                                       │
│  │   ├─ Seller A: ₹3000 × (2500/5000) = ₹1500                              │
│  │   └─ Seller B: ₹2000 × (2500/5000) = ₹1000                              │
│  │                                                                           │
│  └─→ processRefundSplits()                                                  │
│      ├─ Process Seller A refund (₹1500)                                     │
│      └─ Process Seller B refund (₹1000)                                     │
│                                                                              │

┌─────────────────────────────────────────────────────────────────────────────┐
│ 5. RETRY LOGIC                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  Refund Processing Failed                                                   │
│       │                                                                      │
│       ├─→ markRefundFailed()                                                │
│       │   ├─ Status: FAILED                                                 │
│       │   ├─ Retry count: 1                                                 │
│       │   └─ Error message logged                                           │
│       │                                                                      │
│       ├─→ Wait 5 seconds                                                    │
│       │                                                                      │
│       ├─→ retryFailedRefunds()                                              │
│       │   │                                                                  │
│       │   ├─ Get failed refunds (retry_count < 3)                           │
│       │   │                                                                  │
│       │   └─ For each failed refund:                                        │
│       │       ├─ retryRefund()                                              │
│       │       ├─ Status: PROCESSING                                         │
│       │       ├─ processApprovedRefund()                                    │
│       │       │                                                              │
│       │       ├─ If Success                                                 │
│       │       │   └─ Status: COMPLETED ✓                                    │
│       │       │                                                              │
│       │       └─ If Failure                                                 │
│       │           ├─ Retry count: 2                                         │
│       │           └─ Schedule next retry                                    │
│       │                                                                      │
│       └─→ Max 3 retry attempts                                              │
│           └─ After 3 failures: Manual review required                       │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

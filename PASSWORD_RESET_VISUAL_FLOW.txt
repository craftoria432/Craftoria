╔════════════════════════════════════════════════════════════════════════════════╗
║                            ERROR SCENARIOS                                     ║
╚════════════════════════════════════════════════════════════════════════════════╝

❌ Email not found
   └─ Error: "No account found with this email"
   └─ Action: Try with different email

❌ OTP expired (after 10 minutes)
   └─ Error: "OTP expired. Request a new one."
   └─ Action: Click "Resend" to get new OTP

❌ OTP incorrect
   └─ Error: "Incorrect OTP. Please try again."
   └─ Action: Check email and re-enter OTP

❌ OTP already used
   └─ Error: "OTP already used. Request a new one."
   └─ Action: Click "Resend" to get new OTP

❌ Password too short
   └─ Error: "Password must be at least 8 characters"
   └─ Action: Enter longer password

❌ Passwords don't match
   └─ Error: "Passwords do not match"
   └─ Action: Re-enter both passwords carefully

║                            SECURITY FEATURES                                   ║
╚════════════════════════════════════════════════════════════════════════════════╝

🔒 OTP Security:
   • 6-digit random code
   • 10-minute expiry
   • One-time use only
   • Sent via email

🔒 Password Security:
   • Minimum 8 characters required
   • SHA-256 hashing for storage
   • Masked input fields
   • Confirmation required

🔒 Token Security:
   • Reset tokens expire in 15 minutes
   • Tokens marked as used after reset
   • User verification via email

🔒 User Verification:
   • Email lookup before reset
   • OTP validation before password change
   • Multiple validation layers

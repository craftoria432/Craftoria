SELLER PAYMENTS:
═══════════════════════════════════════════════════════════════════════════════

    match /seller_payments/{paymentId} {
      allow read: if isAuthenticated() && (
        request.auth.uid == resource.data.seller_id ||
        request.auth.uid == resource.data.buyer_id ||      ← NEW: Buyer access
        request.auth.uid in resource.data.involved_seller_ids ||
        isAdmin()
      );
      allow write: if false; // Only Cloud Functions
    }


REFUNDS:
═══════════════════════════════════════════════════════════════════════════════

    match /refunds/{refundId} {
      // Read: Buyer, Seller, or Admin
      allow read: if isAuthenticated() && (
        request.auth.uid == resource.data.buyer_id ||
        request.auth.uid == resource.data.seller_id ||
        isAdmin()
      );
      
      // Create: Buyer or Seller
      allow create: if isAuthenticated() && (
        request.auth.uid == request.resource.data.buyer_id ||
        request.auth.uid == request.resource.data.seller_id
      );
      
      // Update: Admin only
      allow update: if isAdmin();
      
      // Delete: No one
      allow delete: if false;
    }

SCENARIO: Buyer orders products from 2 sellers
═══════════════════════════════════════════════════════════════════════════════

    Order #ord_123
    ├── Product A (Seller 1) - PKR 800
    └── Product B (Seller 2) - PKR 700
    Total: PKR 1,500

    Payment Split:
    ├── Payment #pay_456 (Seller 1) - PKR 800
    └── Payment #pay_789 (Seller 2) - PKR 700


REFUND FLOW:
═══════════════════════════════════════════════════════════════════════════════

    Buyer requests refund for entire order
           │
           ▼
    System creates 2 separate refunds:
    ├── Refund #ref_111 (Payment #pay_456) - PKR 800
    └── Refund #ref_222 (Payment #pay_789) - PKR 700
           │
           ▼
    Notifications sent:
    ├── Seller 1 notified about Refund #ref_111
    ├── Seller 2 notified about Refund #ref_222
    └── Admin notified about both refunds
           │
           ▼
    Admin approves both refunds
           │
           ▼
    System processes both refunds
    ├── Refund #ref_111 → Buyer receives PKR 800
    └── Refund #ref_222 → Buyer receives PKR 700
           │
           ▼
    Total refunded: PKR 1,500

7. ANIMATION TIMELINE
================================================================================

BUYER SCREEN - "View Order" CLICK:

T=0ms:
  - User clicks "View Order" button on Order #1
  - Order is at bottom of list (not visible)
  - LazyListState finds index of Order #1

T=50ms:
  - animateScrollToItem(index) called
  - Scroll animation starts
  - Order begins moving up

T=150ms:
  - Scroll animation in progress
  - Order #1 is halfway to top
  - Smooth animation continues

T=300ms:
  - Scroll animation completes
  - Order #1 is now at top
  - Pink highlight visible
  - Dialog opens (Order Details or Track Order)

T=300ms+:
  - User sees highlighted order at top
  - Dialog is open
  - User can interact with dialog


8. SCROLL BEHAVIOR DETAILS
================================================================================

SCROLL CALCULATION:
- Find order index in list: orders.indexOf(order)
- If index >= 0, scroll to that index
- animateScrollToItem(index) scrolls to top of list

SCROLL POSITION:
- Order scrolls to TOP of visible area
- Not centered, not bottom
- Maximum visibility of order card

SCROLL ANIMATION:
- Type: Smooth scroll animation
- Duration: ~300ms (default Compose)
- Easing: Smooth (default)
- No jank or stuttering

SCROLL PERFORMANCE:
- Frame rate: 60fps
- CPU usage: Minimal
- Memory: <1KB
- Battery: Negligible

10. CODE FLOW
================================================================================

BUYER SCREEN CODE FLOW:

onViewDetails = {
    if (!isSelectionMode) {
        selectedOrder = order
        showOrderDetails = true
        // ✅ AUTOSCROLL LOGIC
        coroutineScope.launch {
            val index = orders.indexOf(order)
            if (index >= 0) {
                lazyListState.animateScrollToItem(index)
            }
        }
    }
}

onTrackOrder = { 
    selectedOrder = order
    showTrackingDialog = true
    // ✅ AUTOSCROLL LOGIC
    coroutineScope.launch {
        val index = orders.indexOf(order)
        if (index >= 0) {
            lazyListState.animateScrollToItem(index)
        }
    }
}

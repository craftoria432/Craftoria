  KEY FEATURES
═══════════════════════════════════════════════════════════════════════════════

✓ COUNTDOWN TIMER
  • Starts at 60 seconds when OTP is sent
  • Decrements every second: 60s → 59s → 58s → ... → 0s
  • Prevents spam by disabling resend during countdown

✓ SMART LINK
  • "Resend in Xs" (gray, not clickable) → "Resend OTP" (primary, underlined, clickable)
  • Clear visual indication of when resend is available
  • Professional link styling (underlined text)

✓ USER FEEDBACK
  • Success message: "✓ OTP resent successfully"
  • OTP field auto-clears on resend
  • Loading state during API call
  • Error messages if resend fails

✓ NAVIGATION
  • "Back" button to return to email input
  • Countdown resets when going back
  • Can change email if needed

  TECHNICAL IMPLEMENTATION
═══════════════════════════════════════════════════════════════════════════════

STATE MANAGEMENT:
  var resendCountdown by remember { mutableIntStateOf(0) }

COUNTDOWN LOGIC:
  LaunchedEffect(resendCountdown) {
      if (resendCountdown > 0) {
          kotlinx.coroutines.delay(1000L)
          resendCountdown--
      }
  }

CONDITIONAL RENDERING:
  if (resendCountdown > 0) {
      Text("Resend in ${resendCountdown}s")  // Not clickable
  } else {
      Text("Resend OTP", modifier = Modifier.clickable { ... })  // Clickable
  }

RESEND LOGIC:
  1. Set isLoading = true
  2. Clear OTP field (otp = "")
  3. Call viewModel.sendPasswordResetOtp()
  4. On success: restart countdown (resendCountdown = 60)
  5. Show success message
  6. Set isLoading = false

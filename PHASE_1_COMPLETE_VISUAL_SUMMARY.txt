┌────────────────────────────────────────────────────────────────────────────────┐
│ HOW IT WORKS                                                                   │
└────────────────────────────────────────────────────────────────────────────────┘

Admin Action (Web Dashboard)
        ↓
Firestore Document Updated
        ↓
Cloud Function Triggered
        ↓
Notification Created in Firestore
        ↓
sendNotificationOnCreate Function
        ↓
Get User's FCM Token
        ↓
Send FCM Push via Firebase Messaging
        ↓
Mobile App Receives Push
        ↓
FCMService Displays Notification
        ↓
User Sees System Notification

┌────────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                                │
└────────────────────────────────────────────────────────────────────────────────┘

Issue: "Permission denied" error
  → Enable Blaze plan: firebase billing:set blaze

Issue: "FCM token not found"
  → Mobile app hasn't saved token yet
  → Check users/{userId}/fcm_token field

Issue: Functions not triggering
  → Check Firestore security rules
  → Verify function code has no syntax errors
  → Check function logs: firebase functions:log

Issue: "Quota exceeded"
  → You're using more than free tier (unlikely)
  → Check if you're hitting rate limits

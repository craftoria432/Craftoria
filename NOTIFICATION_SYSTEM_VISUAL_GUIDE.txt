REAL-TIME UPDATE FLOW
================================================================================

SCENARIO 1: Seller Changes Name
─────────────────────────────────

  Notification Created:
  ┌─────────────────────────────────┐
  │ 🏪 Zara Ahmed · 👥 2 Members   │
  └─────────────────────────────────┘
           ↓
  Seller Updates Profile:
  ┌─────────────────────────────────┐
  │ Name: Zara Ahmed → Zara Ali     │
  │ [Save]                          │
  └─────────────────────────────────┘
           ↓
  Firestore Updated:
  ┌─────────────────────────────────┐
  │ users/{sellerId}                │
  │ {                               │
  │   "name": "Zara Ali"            │
  │ }                               │
  └─────────────────────────────────┘
           ↓
  Real-time Listener Fires:
  ┌─────────────────────────────────┐
  │ Listener detects change         │
  │ Fetches new name: "Zara Ali"    │
  │ Updates UI state                │
  └─────────────────────────────────┘
           ↓
  Notification Updates (NO REFRESH NEEDED):
  ┌─────────────────────────────────┐
  │ 🏪 Zara Ali · 👥 2 Members     │
  └─────────────────────────────────┘

REAL-TIME LISTENER LIFECYCLE
================================================================================

Notification Card Created
         ↓
    DisposableEffect Triggered
         ↓
    Set up Listeners:
    ├─ users/{storeId} listener
    └─ co_seller_stores/{storeId} listener
         ↓
    Listeners Active (watching for changes)
         ↓
    Data Changes in Firestore
         ↓
    Listeners Fire
         ↓
    UI State Updated
         ↓
    Recompose (UI updates)
         ↓
    Notification Card Disposed
         ↓
    onDispose Block Executed
         ↓
    Listeners Removed
         ↓
    No More Updates


TROUBLESHOOTING FLOWCHART
================================================================================

Store Name Not Updating?
├─ Is storeId set in notification? → NO → Add storeId
├─ Is seller name updated in users/{sellerId}? → NO → Update profile
├─ Are Firestore rules allowing reads? → NO → Update rules
└─ Check logs for listener errors → YES → Debug error

Member Count Showing 0?
├─ Is storeId set in notification? → NO → Add storeId
├─ Does co_seller_stores/{storeId} exist? → NO → Create store
├─ Does it have member_ids or member_count? → NO → Add members
├─ Are Firestore rules allowing reads? → NO → Update rules
└─ Check logs for listener errors → YES → Debug error

Notifications Not Filtering?
├─ Is category field set correctly? → NO → Use uppercase
├─ Do you have notifications in that category? → NO → Create some
├─ Is filter tab being clicked? → NO → Click tab
├─ Is ViewModel calling filterNotifications()? → NO → Check code
└─ Check logs for filtering errors → YES → Debug error

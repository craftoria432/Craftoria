╔════════════════════════════════════════════════════════════════════════════════╗
║                            REFUND STATE MACHINE                                ║
╚════════════════════════════════════════════════════════════════════════════════╝

Order Delivered/Completed
    ↓
Query Firestore for refunds (NO INTERMEDIATE STATE)
    ↓
Set state directly to:
    ├─ NONE ────────────────→ "Request Refund" button (if within 30 days)
    ├─ REQUESTED ───────────→ "Refund Pending" badge (orange)
    ├─ APPROVED ────────────→ "Refund Processing" badge (blue with spinner)
    ├─ PROCESSING ──────────→ "Refund Processing" badge (blue with spinner)
    ├─ COMPLETED ───────────→ "Refund Done" badge (green with checkmark)
    ├─ REJECTED ────────────→ "Resubmit Refund" button (orange)
    ├─ FINAL_DECISION ──────→ "Refund Denied" badge (gray, disabled)
    └─ FAILED ──────────────→ "Refund Failed" badge (red)

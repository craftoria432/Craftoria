PRODUCTS LISTENER
┌─────────────────────────────────────────────────────────────────────────────┐
│ db.collection("products")                                                   │
│   .whereEqualTo("seller_id", sellerId)  ← Filter by seller                 │
│   .addSnapshotListener { snapshot, error ->                                 │
│       val productCount = snapshot.documents.size                            │
│       trySend(productCount)                                                 │
│   }                                                                         │
│                                                                             │
│ Benefits:                                                                   │
│ • Only fetches seller's products                                            │
│ • Minimal data transfer                                                     │
│ • Fast updates                                                              │
│ • Indexed query for performance                                             │
└─────────────────────────────────────────────────────────────────────────────┘

ORDERS LISTENER
┌─────────────────────────────────────────────────────────────────────────────┐
│ db.collection("orders")                                                     │
│   .whereEqualTo("seller_id", sellerId)  ← Filter by seller                 │
│   .whereEqualTo("status", "pending")    ← Filter by status                 │
│   .addSnapshotListener { snapshot, error ->                                 │
│       val orderCount = snapshot.documents.size                              │
│       trySend(orderCount)                                                   │
│   }                                                                         │
│                                                                             │
│ Benefits:                                                                   │
│ • Only fetches pending orders                                               │
│ • Minimal data transfer                                                     │
│ • Fast updates                                                              │
│ • Composite index for performance                                           │
└─────────────────────────────────────────────────────────────────────────────┘

PAYMENTS LISTENER
┌─────────────────────────────────────────────────────────────────────────────┐
│ db.collection("seller_payments")                                            │
│   .whereEqualTo("seller_id", sellerId)  ← Filter by seller                 │
│   .addSnapshotListener { snapshot, error ->                                 │
│       var totalEarnings = 0.0                                               │
│       snapshot.documents.forEach { doc ->                                   │
│           totalEarnings += doc.getDouble("amount") ?: 0.0                   │
│       }                                                                     │
│       trySend(totalEarnings)                                                │
│   }                                                                         │
│                                                                             │
│ Benefits:                                                                   │
│ • Only fetches seller's payments                                            │
│ • Aggregation done client-side                                              │
│ • Fast updates                                                              │
│ • Indexed query for performance                                             │
└─────────────────────────────────────────────────────────────────────────────┘

## 🔄 Badge Behavior

### When Badge Shows
```
Count > 0 → Badge Visible
Count = 0 → Badge Hidden
Count > 9 → Shows "9+"
```

### Badge Updates
```
User Action
    ↓
Firebase Updated
    ↓
Listener Triggered
    ↓
ViewModel Updated
    ↓
UI Recomposes
    ↓
Badge Updates
```

### Example: Cart Badge
```
User adds item to cart
    ↓
CartViewModel.addToCart()
    ↓
Firebase cart collection updated
    ↓
CartViewModel listener triggered
    ↓
cartCount StateFlow updated
    ↓
HomeScreen recomposes
    ↓
Cart badge shows "1"
```

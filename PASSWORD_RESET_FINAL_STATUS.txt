┌────────────────────────────────────────────────────────────────────────────────┐
│ THE 4-STEP FLOW                                                                │
└────────────────────────────────────────────────────────────────────────────────┘

Step 0: Email Input
├─ User enters registered email
├─ OTP generated (6 random digits)
├─ OTP sent to email
└─ OTP expires in 10 minutes

Step 1: OTP Verification
├─ User enters 6-digit OTP from email
├─ System validates OTP
├─ User can resend OTP
└─ User can go back to email step

Step 2: New Password Input ⭐ NEW
├─ User enters new password (min 8 chars)
├─ User confirms password
├─ System validates passwords match
└─ User can go back to OTP step

Step 3: Success
├─ Success message displayed
├─ User closes dialog
└─ User logs in with new password

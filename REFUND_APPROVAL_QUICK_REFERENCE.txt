QUESTION:
─────────
When refund is approved by seller/admin, what should happen to payment status?

ANSWER:
───────
Payment status should change from COMPLETED → PROCESSING (on approval)
                                    PROCESSING → REFUNDED (on completion)

╔════════════════════════════════════════════════════════════════════════════════╗
║                              STATE TRANSITIONS                                 ║
╚════════════════════════════════════════════════════════════════════════════════╝

STAGE 1: REFUND REQUESTED
  RefundRequest.status = REQUESTED
  SellerPayment.status = COMPLETED ← No change
  SellerPayment.refundAmount = 0.0
  Display: "✅ Completed" | "Request Refund"

                              ↓

STAGE 2: REFUND APPROVED ⭐ KEY
  RefundRequest.status = APPROVED_BY_SELLER
  SellerPayment.status = PROCESSING ← CHANGED
  SellerPayment.refundAmount = <amount> ← POPULATED
  SellerPayment.refundReason = <reason> ← POPULATED
  Display: "⏳ Refund Processing" | "Refund Processing"
  Notification: "Refund Approved"

                              ↓

STAGE 3: REFUND PROCESSING
  RefundRequest.status = PROCESSING
  SellerPayment.status = PROCESSING ← No change
  Display: "⏳ Refund Processing" | "Refund Processing"

                              ↓

STAGE 4: REFUND COMPLETED ✅ FINAL
  RefundRequest.status = COMPLETED
  SellerPayment.status = REFUNDED ← CHANGED
  SellerPayment.refundDate = <timestamp> ← SET
  Display: "✅ Refunded" | "Refund Done"
  Notification: "Refund Completed"

╔════════════════════════════════════════════════════════════════════════════════╗
║                         WHAT CHANGES ON APPROVAL                               ║
╚════════════════════════════════════════════════════════════════════════════════╝

1. RefundRequest.status
   BEFORE: REQUESTED
   AFTER:  APPROVED_BY_SELLER (or APPROVED_BY_ADMIN)

2. SellerPayment.status ⭐ CRITICAL
   BEFORE: COMPLETED
   AFTER:  PROCESSING
   WHY:    Signals refund is being processed

3. SellerPayment.refundAmount ⭐ CRITICAL
   BEFORE: 0.0
   AFTER:  <refund_amount>
   WHY:    Tracks refund amount

4. SellerPayment.refundReason
   BEFORE: ""
   AFTER:  <reason>
   WHY:    Audit trail

5. SellerPayment.refundDate
   BEFORE: null
   AFTER:  null (still null - only set on completion)
   WHY:    Only set when actually completed

╔════════════════════════════════════════════════════════════════════════════════╗
║                         WHAT CHANGES ON COMPLETION                             ║
╚════════════════════════════════════════════════════════════════════════════════╝

1. RefundRequest.status
   BEFORE: PROCESSING
   AFTER:  COMPLETED

2. SellerPayment.status ⭐ CRITICAL
   BEFORE: PROCESSING
   AFTER:  REFUNDED
   WHY:    Indicates refund successfully processed

3. SellerPayment.refundDate ⭐ CRITICAL
   BEFORE: null
   AFTER:  System.currentTimeMillis()
   WHY:    Marks when refund completed

PAYMENT HISTORY SCREEN:
───────────────────────
if (payment.status == "refunded") {
    show("✅ Refunded")
    show(refundAmount)
} else if (payment.status == "processing" && payment.refundAmount > 0) {
    show("⏳ Refund Processing")
    show(refundAmount)
} else if (payment.status == "completed") {
    show("✅ Completed")
} else {
    show(payment.status)
}

MY ORDERS SCREEN:
─────────────────
when (refundState) {
    NONE → show("Request Refund", orange)
    REQUESTED → show("Refund Pending", orange)
    APPROVED, PROCESSING → show("Refund Processing", blue, spinner)
    COMPLETED → show("Refund Done", green, checkmark)
    REJECTED → show("Resubmit Refund", orange)
    FINAL_DECISION → show("Refund Denied", gray)
}

╔════════════════════════════════════════════════════════════════════════════════╗
║                         BACKEND IMPLEMENTATION                                 ║
╚════════════════════════════════════════════════════════════════════════════════╝

WHEN SELLER/ADMIN APPROVES REFUND:
──────────────────────────────────
1. Update RefundRequest.status = APPROVED_BY_SELLER
2. Update SellerPayment.status = PROCESSING ← KEY
3. Set SellerPayment.refundAmount = <amount> ← KEY
4. Set SellerPayment.refundReason = <reason>
5. Send notification to buyer

WHEN REFUND COMPLETES:
──────────────────────
1. Update RefundRequest.status = COMPLETED
2. Update SellerPayment.status = REFUNDED ← KEY
3. Set SellerPayment.refundDate = now ← KEY
4. Send notification to buyer

WHEN REFUND REJECTED:
─────────────────────
1. Update RefundRequest.status = REJECTED_BY_SELLER
2. Keep SellerPayment.status = COMPLETED (no change)
3. Send notification to buyer

# Craftoria Logo Creation Prompt

## Logo Design Brief for AI Image Generation

Create a modern, professional logo for "Craftoria" - a mobile marketplace app for handcrafted products and artisan goods.

### Design Requirements:

**Style:**
- Modern, clean, and minimalist design
- Professional yet warm and approachable
- Suitable for both app icon (square) and splash screen
- Scalable from 16px to 512px without losing clarity

**Visual Elements:**
- Incorporate subtle craft/handmade symbolism (e.g., stylized hands, thread, needle, or abstract craft tools)
- Use geometric shapes that work well in circular app icons
- Consider a monogram or lettermark using "C" for Craftoria
- Optional: Include a small craft element (like a stitch pattern, woven texture, or artisan tool silhouette)

**Color Palette:**
- Primary: Deep teal or emerald green (#2D7A6E or #1B5E52) - represents creativity and trust
- Secondary: Warm terracotta or burnt orange (#E07A5F or #D4663F) - represents handmade warmth
- Accent: Gold or amber (#F4A261 or #E9C46A) - represents quality and craftsmanship
- Alternative: Use a gradient between primary and secondary colors
- Ensure high contrast for visibility on both light and dark backgrounds

**Typography (if including text):**
- Font: Modern sans-serif or elegant serif
- Text: "Craftoria" or just "C"
- Keep text minimal for app icon version
- Full wordmark can be used for splash screen

**Technical Specifications:**
- Format: Vector-style design (clean edges, no photo-realistic textures)
- Background: Transparent or solid color that works with Material Design
- Icon version: Centered design with 20% padding from edges
- Splash version: Can include full wordmark below the icon

### Prompt Examples:

**Option 1 - Minimalist Geometric:**
```
Create a modern minimalist logo for "Craftoria" handcraft marketplace app. Design features a geometric letter "C" formed by interlocking craft elements (needle and thread silhouette). Use deep teal (#2D7A6E) and warm terracotta (#E07A5F) gradient. Clean lines, professional, suitable for app icon. White background, centered composition with padding.
```

**Option 2 - Artisan Badge:**
```

Color palette: emerald green (#1B5E52), burnt orange (#D4663F), and gold accent (#F4A261). Modern, professional, scalable design for mobile app icon.
```

```
Create an abstract logo combining craft symbolism for "Craftoria" app. Design uses flowing lines suggesting thread, fabric, or creative process, forming a recognizable icon. Gradient from deep teal to warm orange. Minimalist, modern, professional. Suitable for square app icon with transparent background.
```

**Option 4 - Lettermark with Craft Detail:**
```
Design a sophisticated lettermark logo featuring stylized "C" for "Craftoria". Incorporate subtle craft details like stitch marks or woven texture within the letter. Use solid deep teal (#2D7A6E) with gold (#F4A261) accent details. Clean, professional, works at small sizes for app icon.
```

### Usage Guidelines:

**App Icon (1024x1024px):**
- Use icon-only version without text
- Ensure design is recognizable at 48x48px
- Add subtle shadow or depth for dimension
- Follow Android Adaptive Icon guidelines (safe zone)

**Splash Screen:**
- Center the icon
- Add "Craftoria" wordmark below in elegant typography
- Use tagline: "Handcrafted with Love" or "Artisan Marketplace"
- Background: Gradient or solid color from palette
- Ensure 2-3 second viewing comfort

### Design Principles:
- Memorable and unique
- Reflects handmade quality and craftsmanship
- Professional enough for sellers to trust
- Warm enough for buyers to feel welcomed
- Timeless design that won't feel dated quickly

## Post-Generation Steps:
1. Generate multiple variations
2. Test at different sizes (512px, 192px, 48px)
3. Check visibility on light and dark backgrounds
4. Vectorize using Adobe Illustrator or Figma
5. Create adaptive icon versions for Android
6. Export in required formats (PNG, SVG, WebP)

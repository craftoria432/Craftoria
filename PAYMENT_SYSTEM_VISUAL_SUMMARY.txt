┌─────────────────────────────────────────────────────────────────────────────┐
│ 5. DATA FLOW                                                                │
└─────────────────────────────────────────────────────────────────────────────┘

  Order Placed
  ↓
  PaymentRepository.processOrderPayments(order)
  ├─ For each seller in order.items:
  │  ├─ Create SellerPayment record
  │  ├─ Set status = "pending"
  │  ├─ Link to seller_id, buyer_id, order_id
  │  └─ Save to seller_payments collection
  │
  └─ Send notification to each seller

  Order Status Changes
  ↓
  OrderRepository.updateOrderStatus(order, newStatus)
  ├─ If newStatus == "delivered":
  │  ├─ Get all payments for this order
  │  ├─ Update each payment.status = "completed"
  │  ├─ Update payment.payment_date = now()
  │  └─ Send notification to each seller
  │
  └─ Dashboard recalculates earnings

  Seller Views Dashboard
  ↓
  DashboardRepository.getDashboardStats(sellerId)
  ├─ Query seller_payments where seller_id == sellerId
  ├─ Filter for status == "completed"
  ├─ Sum amounts for total earnings
  ├─ Calculate this month's earnings
  └─ Return stats to SellerDashboardScreen

  Seller Views Payment History
  ↓
  PaymentRepository.getSellerPayments(sellerId)
  ├─ Query seller_payments where seller_id == sellerId
  ├─ Sort by created_at (newest first)
  ├─ Calculate statistics
  └─ Return to SellerPaymentsScreen

  Buyer Views Payment History
  ↓
  PaymentRepository.getBuyerPayments(buyerId)
  ├─ Query seller_payments where buyer_id == buyerId
  ├─ Sort by created_at (newest first)
  ├─ Calculate statistics
  └─ Return to PaymentHistoryScreen
